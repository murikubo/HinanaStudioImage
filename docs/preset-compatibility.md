# 인물·색감 프리셋 (v0.17)

왼쪽 **인물 · 나의 프리셋**에서 내추럴 인물, 매트 스킨, 소프트 인물
프리셋을 적용할 수 있습니다. 피부 보정에는 기존 부드럽게·붉은 기·밝기와
함께 피부 톤 균일화·번들거림 완화가 제공됩니다. 피부색을 기준으로 선택하는
방식입니다. 별도의 얼굴·체형 AI 도구는 랜드마크 모델을 사용하지만 피부 도구에는
성별/연령별 보정이나 얼굴 마스크가 적용되지 않습니다. 비슷한 피부색 배경에도
영향을 줄 수 있으므로 원본 비교로 확인하세요.

## 저장과 재사용

- 적용 강도(0~100%)를 정하고 프리셋을 누릅니다. 0%는 아무것도 변경하지 않습니다.
- **저장 · 가져오기 · 동기화**를 펼쳐 이름과 저장 범위(인물/색감/인물+색감)를
  선택한 뒤 현재 보정을 저장합니다. 사용자 프리셋은 IndexedDB에 최대 100개까지
  저장되며 앱을 다시 열어도 유지됩니다.
- 선택한 사용자 프리셋을 현재 보정으로 업데이트하거나 이름 변경·삭제할 수 있습니다.
- `.hinanapreset` 파일은 인물 보정과 LUT를 포함한 Hinana 보정을 그대로 저장합니다.
  프리셋 보관함은 사진 프로젝트와 별개이므로 다른 기기로 옮길 때 파일을 내보내세요.
- 동기화는 현재 사진의 선택 범위 보정을 다른 사진 전체 또는 별표 사진에 복사합니다.
  각 사진의 원본·크롭·회전·반전·리퀴파이·마스크·HDR 설정을 유지합니다.
  적용한 사진마다 실행 취소할 수 있습니다.

## 공통 형식 호환 범위

Evoto가 공식 지원하는 공통 형식은 XMP와 CUBE입니다.
<https://support.evoto.ai/how-to-use-preset/>

| 형식 | 가져오기 | 내보내기 |
| --- | --- | --- |
| `.hinanapreset` | 인물·색감·LUT | 전체 선택 범위 |
| `.xmp` | 노출, 대비, 하이라이트/그림자, 흰색/검정, 생동감, 채도, 비네팅, 8색 HSL | 같은 기본 색상·HSL 항목 |
| `.cube` | 2~65 크기 표준 3D LUT, DOMAIN_MIN/MAX, 삼선형 보간 | Hinana 프리셋에 포함하여 보존 |
| Evoto 전용 공유 토큰 | 미지원 | 미지원 |

XMP는 Adobe Camera Raw 네임스페이스를 파싱합니다. AI 인물 설정, 사용자 카메라
프로파일, 절대 색온도/틴트, 마스크, 임의 톤 곡선 등 미지원 항목은 적용하지 않고
프리셋 안내에 표시합니다. 엔진과 RAW 현상 차이로 원래 프로그램과 동일한 결과를
보장하지 않습니다. 외부 프로그램으로 내보내는 XMP에는 피부·LUT·Hinana 곡선이
포함되지 않습니다. Evoto 자체에 실제 가져오는 상호운용 테스트는 수행하지 않았습니다.

CUBE는 **인코딩된 sRGB용 LUT**로 해석하며 P3 작업 공간에서는 선형 색공간 변환 후
적용합니다. HDR은 픽셀별 게인을 보존하여 적용하며, HDR/Log 원본의 전문 입력·출력
변환을 대신하지 않습니다. 1D/3D 결합 LUT와 Log·카메라 전용 LUT의 자동 입력 변환은
지원하지 않습니다. 파일당 24MB 제한이 있습니다.

LUT와 피부 보정은 공통 픽셀 파이프라인을 사용하여 미리보기와 내보내기에 함께
적용됩니다. Windows Direct3D 리퀴파이는 유지되며 LUT와 피부 보정은 CPU에서 처리합니다.
프로젝트 형식은 v8이며 기존 v1~v7 프로젝트를 읽을 수 있습니다.

v0.17의 얼굴·체형 설정과 피부 글로시는 인물 프리셋에 포함됩니다.
사진별 인식 좌표와 크롭은 프리셋에 포함되지 않으며 다른 사진에서는 새로 인식합니다.
Hinana 공유 토큰은 [인물 AI·크롭·토큰 안내](portrait-ai.md)를 참고하세요.

## 검증

`npm test`는 LUT 보간·알파·HDR/P3·프리셋 범위·형식 검증·XMP 매핑·피부 보정을
검증합니다. 빌드 후 `node tests/presets-smoke.mjs`는 실제 앱의 프리셋 저장/복원,
파일 왕복, XMP·CUBE 적용, 보정 동기화와 실행 취소를 검증합니다.
